This is a tiny local wrapper — your prompts go to the model behind your terminal, straight from the browser.

Help

  • New chat starts a fresh conversation with a clean context.
  • Click any chat in the sidebar to reopen it with its memory intact.
  • Search filters your saved chats by title.
  • While a reply streams, the send button becomes stop — or press Esc. Whatever arrived so far is kept.
  • Hover a chat in the sidebar to rename or delete it. Deleting also drops the session on disk.
  • Hover a code block to copy it. The model dropdown overrides .env for new messages.
  • Everything is stored locally: chats in your browser, sessions on disk.
